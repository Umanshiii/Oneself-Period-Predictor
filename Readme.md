Oneself – Period Predictor
Overview

Oneself is a web-based menstrual cycle tracking and prediction application designed to help users monitor their cycle history and estimate upcoming periods using historical data analysis.

The system focuses on simplicity, usability, and practical prediction logic.

Problem Statement

Many people track menstrual cycles manually using calendars or basic apps that do not adapt to individual variability. Irregular cycles reduce prediction accuracy when static methods are used.

Oneself aims to provide a more structured and data-driven approach to prediction based on user-specific historical patterns.

Features

Period start and end date logging

Historical cycle tracking

Automatic average cycle length calculation

Next period prediction

Estimated ovulation window calculation

Clean and minimal interface

How It Works

The prediction logic is based on:

Calculating the average cycle length from recorded history

Estimating the next period start date

Determining the approximate fertile window based on cycle midpoint

If historical data increases, prediction accuracy improves.
